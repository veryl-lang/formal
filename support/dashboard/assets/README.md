# Brand assets

The logo is from [veryl-lang.org](https://veryl-lang.org/logo.png). The dashboard
uses the site's light-theme brand colors, Fira Sans, and JetBrains Mono. Semantic
status colors use darker variants for compact text.

Unmodified fonts are bundled for offline HTML artifacts. Fira Sans weights
400/500/600/700 and JetBrains Mono weight 400 were retrieved through the Google
Fonts stylesheet used by the official site. Their SIL Open Font License notices
are included alongside the font files.

The builder embeds these assets as data URLs; viewing the HTML does not fetch
fonts or images from external servers. Follow the logo link to open the official
site.
